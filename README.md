# goit-pycore-hw-07

Консольний бот-асистент на базі класів `AddressBook`, `Record`, `Name`, `Phone` та `Birthday`.

## Підтримувані команди

- `hello` — привітання.
- `add [ім'я] [телефон]` — додати контакт або новий номер телефону до існуючого контакту.
- `change [ім'я] [старий телефон] [новий телефон]` — змінити номер телефону.
- `phone [ім'я]` — показати телефони контакту.
- `all` — показати всі контакти.
- `add-birthday [ім'я] [DD.MM.YYYY]` — додати день народження контакту.
- `show-birthday [ім'я]` — показати день народження контакту.
- `birthdays` — показати контакти, яких потрібно привітати протягом наступних 7 днів.
- `close` або `exit` — завершити роботу бота.

## Запуск та тести

```bash
python main.py
python -m unittest -v
```
